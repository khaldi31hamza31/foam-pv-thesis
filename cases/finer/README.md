# Cas finer

Quatrième et dernier point de l'étude de convergence de maillage (voir
le README principal du dossier `plaque_30deg/`).

- `lc_plate = 0.003*b`, `lc_far = 0.3*b`
- 183 282 cellules
- kN = 0.557 (oscillant, moyenne sur la seconde moitié du calcul)

L'écart avec le cas fin (kN = 0.563) reste faible (~1 %), ce qui
confirme que la valeur s'est stabilisée autour de kN ≈ 0.56.
